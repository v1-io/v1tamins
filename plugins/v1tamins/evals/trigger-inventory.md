# Skill Trigger Inventory

Use this inventory before editing descriptions. The question is not only whether
the current wording is concise; it is whether the skill has the right trigger
contract at all.

| Skill | Trigger assessment | Candidate trigger examples | Near-miss neighbors | Invocation posture | Budget risk |
| --- | --- | --- | --- | --- | --- |
| `v1-address-review` | Right trigger: resolving already-existing review comments and conversations. | "work through the unresolved PR comments"; "reply to this bot review with fixes" | `v1-deep-review`, `v1-review-board`, `v1-pr` | selective implicit; GitHub replies, resolution, and push require explicit request | medium |
| `v1-autoresearch-skill` | Broad optimization trigger; should stay measurable-target only. | "run an optimization loop on this metric"; "keep variants that improve the score" | `v1-deep-research`, `v1-goldpan`, `v1-simplify` | explicit only; long-running autonomous loop is a deliberate ritual | low |
| `v1-bare-bones` | Strong trigger for reducing scope before execution. | "strip this plan to the minimum useful version"; "remove the bells and whistles" | `v1-strategy-review`, `v1-interview-me`, `v1-prd` | high-recall implicit | low |
| `v1-canon2skill` | Right trigger: turn source material into reusable skill ideas. | "what skills could come from this paper"; "extract agent workflows from these notes" | `v1-skilling-it`, `v1-deep-research`, `v1-prompt-engineering` | high-recall implicit; live evals show its natural-phrase traffic misroutes to `v1-skilling-it` when hidden | low |
| `v1-changelog` | Narrow release-note trigger is good. | "write release notes from merged PRs"; "summarize what shipped this week" | `v1-docs-freshness`, `v1-pr-description`, `v1-goldpan` | high-recall implicit | low |
| `v1-debug` | Strong failure/root-cause trigger. | "why is this error happening"; "reproduce and fix this flaky behavior" | `v1-fix-tests`, `v1-diagnosing-constraints`, `v1-e2e-testing` | high-recall implicit | low |
| `v1-deep-research` | Trigger should require multi-source research, not simple lookup. | "do deep research on this market"; "compare the state of the art across sources" | `v1-autoresearch-skill`, `v1-canon2skill`, `v1-phone-a-friend` | selective implicit; time-consuming | medium |
| `v1-deep-review` | Right trigger: merge-risk and structural review of a branch or PR (code, docs, or config); the single in-agent review skill. | "review this PR for bugs"; "audit this branch for maintainability" | `v1-review-board`, `v1-address-review`, `v1-simplify` | selective implicit; posting to GitHub is an explicit external write | low |
| `v1-deslop` | Good slop-removal trigger; distinguish from a general cleanup pass. | "remove AI-generated boilerplate"; "delete defensive checks that add no value" | `v1-simplify`, `v1-hindsight-refactor` | high-recall implicit | low |
| `v1-diagnosing-constraints` | Right non-code bottleneck trigger; avoid software exception debugging. | "find the bottleneck in this process"; "why is this queue stuck" | `v1-debug`, `v1-strategy-review`, `v1-learning-from-customers` | high-recall implicit | low |
| `v1-docs-freshness` | Good post-change documentation sync trigger. | "update docs after this change"; "make README match the shipped feature" | `v1-changelog`, `v1-pr-description`, `v1-skilling-it` | high-recall implicit | low |
| `v1-e2e-testing` | Right browser/end-to-end test trigger. | "add Playwright coverage for this flow"; "debug this flaky browser test" | `v1-write-tests`, `v1-fix-tests`, `v1-debug` | high-recall implicit | low |
| `v1-fix-tests` | Strong failing-suite trigger; keep separate from writing new coverage. | "tests are failing after my change"; "make the suite green" | `v1-write-tests`, `v1-debug`, `v1-e2e-testing` | high-recall implicit | low |
| `v1-goldpan` | Narrow mining-for-compound trigger; should not catch ordinary changelog work. | "pan recent sessions for lessons"; "find compound-worthy solved problems" | `v1-changelog`, `v1-docs-freshness`, `v1-canon2skill` | explicit only; deliberate mining ritual with external tool dependency | low |
| `v1-hindsight-refactor` | Good second-pass rewrite trigger after a working but messy fix. | "delete this exploratory fix and reimplement cleanly"; "do a second-pass rewrite" | `v1-simplify`, `v1-deslop` | selective implicit | medium |
| `v1-html-it` | Good artifact trigger; ensure it catches visual/explainer/report prompts. | "make this a shareable HTML report"; "turn this analysis into an interactive page" | `v1-md2docs`, `v1-reviewing-data-graphics`, `v1-stickify` | high-recall implicit | low |
| `v1-interview-me` | Right early idea interrogation trigger; composes the interview loop and an opt-in with-docs glossary/ADR pass. | "interview me about this feature idea"; "help me think through this concept" | `v1-prd`, `v1-strategy-review`, `v1-learning-from-customers`, `v1-shared-language` | high-recall implicit | low |
| `v1-land-pr` | Current trigger is too action-chain-first; should start with complete-work PR handoff. | "land this completed branch"; "commit, push, open, monitor, and ready this PR" | `v1-pr`, `v1-pr-description`, `v1-deep-review` | explicit only; pushes and external workflow updates | high |
| `v1-learning-from-customers` | Right customer-evidence trigger. | "plan customer discovery"; "audit these interview notes for real demand" | `v1-testing-prototypes`, `v1-interview-me`, `v1-strategy-review` | high-recall implicit | low |
| `v1-md2docs` | Current trigger should start with user-requested Google Doc conversion. | "turn this markdown into a Google Doc"; "publish this .md as a formatted doc" | `v1-html-it`, `v1-stickify`, `v1-docs-freshness` | explicit only; creates Drive docs | high |
| `v1-menu` | Router: the user asks which v1 skill fits the situation. | "which v1 skill should I use for this"; "show me the v1 skills menu" | `v1-skilling-it`, `v1-canon2skill` | selective implicit; read-only index that must stay reachable from natural which-skill questions | low |
| `v1-phone-a-friend` | Strong second-opinion/delegation trigger. | "get another model's opinion"; "ask a peer agent to review this" | `v1-review-board`, `v1-deep-research`, `v1-deep-review` | selective implicit; may launch external peers | medium |
| `v1-pr` | Good general PR creation trigger; distinguish from land full CI workflow. | "create a draft PR for this branch"; "ship this as a PR" | `v1-land-pr`, `v1-pr-description`, `v1-deep-review` | explicit only; pushes/PR creation | high |
| `v1-pr-description` | Good title/body trigger. | "write the PR description"; "refresh the PR body from the diff" | `v1-pr`, `v1-changelog`, `v1-deep-review` | high-recall implicit; posting remains explicit | low |
| `v1-prd` | Narrow PRD from ticket/feature trigger. | "write a PRD for this feature"; "turn this ticket into requirements" | `v1-interview-me`, `v1-strategy-review`, `v1-bare-bones` | selective implicit; Linear updates require explicit request | medium |
| `v1-prompt-engineering` | Right trigger: prompt/system-prompt/hook/skill review and migration for any model or host; GPT-5.5/OpenRouter specifics load `references/gpt-5-5-patterns.md`. | "improve this system prompt"; "migrate this GPT-5.5 OpenRouter prompt" | `v1-skilling-it` | high-recall implicit | low |
| `v1-prove-work` | Good visual demo trigger, but upload/embed side effects need explicit intent. | "record a GIF demo for the PR"; "make visual proof of this UI change" | `v1-pr-description`, `v1-html-it`, `v1-reviewing-usability` | explicit only; records browser proof and may publish artifacts | high |
| `v1-review-board` | Trigger should emphasize multi-agent review; applying/pushing findings must be gated. | "convene a multi-agent review board"; "fan out review to several peer agents" | `v1-phone-a-friend`, `v1-deep-review`, `v1-address-review` | explicit only; launches peers and may push fixes | high |
| `v1-reviewing-data-graphics` | Good chart/dashboard truthfulness trigger. | "review this chart for misleading signals"; "audit this dashboard's metrics display" | `v1-reviewing-usability`, `v1-html-it`, `v1-stickify` | high-recall implicit | low |
| `v1-reviewing-usability` | Good UI/product-flow review trigger. | "review this UI flow"; "why is this interaction confusing" | `v1-reviewing-data-graphics`, `v1-strategy-review`, `v1-html-it` | high-recall implicit | low |
| `v1-shared-language` | Right domain-vocabulary trigger; also exposes an inline single-term upsert driven by `v1-interview-me`'s with-docs mode. | "define the domain terms from this conversation"; "create a ubiquitous language glossary" | `v1-prd`, `v1-interview-me`, `v1-skilling-it` | high-recall implicit; writes local file | medium |
| `v1-simplify` | Merged cleanup skill: reuse/quality/efficiency + KISS/DRY/SOLID + cognitive complexity, on the diff or named files. | "clean up this diff"; "refactor this module"; "reduce complexity" | `v1-deslop`, `v1-hindsight-refactor`, `v1-deep-review` | high-recall implicit | low |
| `v1-skilling-it` | Right skill-authoring trigger. | "improve this skill description"; "write a reusable agent skill" | `v1-canon2skill`, `v1-prompt-engineering`, `v1-docs-freshness` | high-recall implicit | low |
| `v1-stickify` | Current description is too long; trigger should be sticky communication copy. | "make this message memorable"; "improve this launch copy so it sticks" | `v1-html-it`, `v1-md2docs`, `v1-pr-description` | high-recall implicit | high |
| `v1-strategy-review` | Good strategy/scope review trigger. | "review this plan for hidden assumptions"; "is this ambitious enough" | `v1-bare-bones`, `v1-interview-me`, `v1-learning-from-customers` | high-recall implicit | low |
| `v1-testing-prototypes` | Good prototype-test planning trigger. | "write a user test plan for this prototype"; "synthesize these prototype sessions" | `v1-learning-from-customers`, `v1-reviewing-usability`, `v1-interview-me` | high-recall implicit | low |
| `v1-write-tests` | Strong new-coverage trigger; keep separate from failing-suite repair. | "add unit tests for this parser"; "write coverage for the new behavior" | `v1-fix-tests`, `v1-e2e-testing`, `v1-debug` | high-recall implicit | low |
