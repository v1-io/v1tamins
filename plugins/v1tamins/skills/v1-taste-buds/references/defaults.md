# Default looks

As of 2026-11. This list is dated on purpose. Default looks change with each
model generation and with each popular design skill, so recheck it against
current output before you rely on it, and remove an entry that no longer
appears.

These are the looks a model reaches for whatever the subject. Each one is a
sound choice for some brief. The fault is using one because nothing was
decided.

## How to use the list

Compare each tasting variant and each plan against it. Where the work matches
an entry on an axis the brief left free, change that axis to something the
subject justifies, and say what you changed.

The brief and the existing system always win. When either one asks for a look
on this list, build that look well.

## Whole-page looks

- A neutral sans-serif on white with a purple-to-blue gradient, a centred
  hero, and three feature cards in a row.
- A warm cream background, a high-contrast serif headline with one word in
  italic, and a terracotta or clay accent.
- A near-black background with a single acid-green or orange-red accent.
- Newspaper styling: hairline rules, square corners, and dense columns.
- The card kit: all content cut into identical rounded cards with one soft
  grey shadow, cards inside cards, and a gradient wash for decoration.
- The metric hero: one big number, a small label, and a row of supporting
  statistics.

## Recurring details

- A small all-caps label above every heading.
- Numbered markers (01, 02, 03) on content that is not a sequence.
- Text filled with a gradient, or one headline word in a second colour.
- Blurred glass panels used as decoration.
- Pill-shaped buttons and fully rounded corners on everything.
- A coloured bar down one side of a rounded box.
- A monospace face used to look technical, away from code and data.
- An arrow added to every link and button label.
- Emoji standing in for an icon set.
- The same fade-and-slide-up entrance on every section, and a hover lift on
  every card.

## Copy

- Headline verbs and adjectives that fit any product: "seamless",
  "effortless", "supercharge", "unlock".
- Feature names and benefits written before the product is understood.
- Statistics, customer names, quotes, or reviews that nobody supplied. Leave
  the space empty and say what is needed; never fill it with an invention.
